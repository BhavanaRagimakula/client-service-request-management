Client Service Request Management

A full-stack service request management application for creating, viewing, and managing client service requests through a web-based interface.

Technologies
Frontend: React.js, JavaScript, HTML5, CSS3
Backend: Node.js, Express.js
API: REST APIs
Python: Request analytics and automated testing
Testing: PyTest
Version Control: Git & GitHub
Main Features
Create and manage client service requests
View service request details
RESTful CRUD API operations
Request status and priority management
React-based user interface
Request analytics using Python
Input validation and error handling
Automated unit testing with PyTest
Modular frontend and backend structure

Setup
. Clone the repository
git clone https://github.com/BhavanaRagimakula/client-service-request-management.git
cd client-service-request-management
2. Backend Setup
cd backend
npm install

Start the backend:

node server.js

The backend runs locally on the configured server port.

3. Frontend Setup

Open another terminal:

cd frontend
npm install
npm run dev

Open the local URL shown by the frontend development server.

Run Python Tests

From the project root:

pytest
